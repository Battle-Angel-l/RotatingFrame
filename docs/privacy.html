RotatingBot Privacy Policy

Last updated: 2026-06-17

This Privacy Policy explains how RotatingBot (the "Bot") handles information when used on Discord.

1. Information We Process

The Bot may process the following data to function:

  • Discord server (guild) ID
  • Discord channel ID configured for updates
  • Discord message ID used for auto-updating posts
  • slash command interaction metadata needed to respond to commands

2. Information We Do Not Intentionally Collect

  • message content outside command interactions
  • private messages for profiling or marketing
  • payment or financial data

3. Purpose of Processing

Data is processed only to:

  • deliver bot features and command responses;
  • store posting configuration for automated updates;
  • operate and troubleshoot the Bot.

4. Data Storage and Retention

Minimal configuration data may be stored while the Bot is active. Data is retained only as needed to operate the Bot and may be deleted when no longer required.

5. Data Sharing

We do not sell personal data. Data may be processed by infrastructure providers required to operate the Bot (for example, Discord and hosting services).

6. Security

Reasonable measures are used to protect configuration and operational data, but no system is guaranteed to be completely secure.

7. Children’s Privacy

The Bot is not intended for children under the minimum age required by Discord and applicable law.
